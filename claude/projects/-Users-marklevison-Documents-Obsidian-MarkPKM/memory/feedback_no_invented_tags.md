During OmniFocus inbox triage (and tagging generally), don't invent extra tags without discussing their value with Mark first. Example: he rejected an auto-added `Errands` tag on a coffee-shop errand.

**Why:** Speculative tags add noise to his tag system and aren't worth the cleanup.

**How to apply:** Propose a project destination without tags unless the tag is (a) a documented convention (e.g. Ideas & Reading theme tags: `AI Exploration`, `Business Strategy`, `Tooling Curiosity`) or (b) explicitly asked for. Even for documented conventions, surface the tag as a question rather than applying it silently. See [[omnifocus-workflow]] tag section and the inbox-triage rule "only tag when obvious."

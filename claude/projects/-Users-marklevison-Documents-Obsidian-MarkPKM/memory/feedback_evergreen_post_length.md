When drafting evergreen social posts for Mark, they can afford to be a bit longer than a bare hook. The ~450-500 character target used in the 2026-06 "next-few-days" batch was on the tight side.

**Why:** Mark's steer (2026-06-14): "evergreen posts can afford to be a bit longer." Long-form is the stronger signal for him generally (he said the same about the blog/course pieces), so don't reflexively compress evergreen to the minimum.

**How to apply:** Default evergreen bodies to a fuller length (think Mastodon-room, roughly 600-900 chars / a short LinkedIn post) rather than ~450-500, unless he asks for short. The hard platform caps still hold: Mastodon 500, Bluesky 290, so the longer body is the LinkedIn-leaning version and gets condensed per platform at JSON time. Pairs with [[reference-glass-one-third-full]] and the evergreen-posting skill in the agile-pain-relief-astro repo.

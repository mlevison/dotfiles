When drafting LinkedIn/social posts from newsletter content (see [[linkedin-style]] draft mode), pull an **older** newsletter issue, not a recent one.

**Why:** Two reasons. (1) Reposting a fresh issue publicly makes current subscribers feel the newsletter isn't a special/early perk. (2) More importantly, the anecdotes in recent issues have usually **already been posted to LinkedIn** organically, so redrafting them is redundant. A ~3-week gate proved too lenient (Mark rejected a 24-day-old issue for this reason on 2026-07-20).

**How to apply:** Prefer issues that are clearly older (many weeks to months) and whose stories haven't been posted recently. Still respect the "not already mined for social" log in `complete-social-media-calendar.md`. When unsure which older issue, offer a couple and let Mark pick.

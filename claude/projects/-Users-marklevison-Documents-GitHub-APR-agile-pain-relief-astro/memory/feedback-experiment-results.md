---
name: Experiment result conventions
description: How to classify marketing experiment outcomes -- not having time to run an experiment is not a failure
type: feedback
---

Do not mark a marketing experiment as "Failed" when the experiment simply was not run due to time constraints. Use "Not run" instead.

**Why:** Not having time to execute an experiment is a normal reality, not a failure. "Failed" should be reserved for experiments that were actually run and produced negative or inconclusive results. Conflating "didn't get to it" with "tried and it didn't work" distorts the experiment log.

**How to apply:** When updating Marketing Experiments.md, use these result categories:
- **Succeeded** -- experiment ran and produced positive results
- **Failed** -- experiment ran and did not produce the desired outcome
- **Inconclusive** -- experiment ran but data was insufficient or ambiguous
- **Not run** -- experiment was planned but not executed (time, priorities, etc.)
- **In progress** -- experiment is underway, results pending
